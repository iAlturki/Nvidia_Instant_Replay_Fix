# AI agent icon sources

Setup design, page, and prompt: **iAlturki**.

The following third-party marks identify agents users may choose for the
setup prompt. They do not indicate partnership, sponsorship, endorsement,
or a claim that every agent has been tested with every project. Use an agent
with the access needed by the prompt.

Brand marks are the property of their respective owners and are **excluded
from this project's CC BY-NC-SA/GPL license grants**. Original shapes, colors,
and aspect ratios are preserved; only display size changes. No runtime
request to the logo owners is required: these are locally bundled assets.
